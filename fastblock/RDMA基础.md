
1.首先需要一个PD 保护域，申请QP 和注册MR，和创建其他的RDMA资源都需要 PD。

2.整体流程
```
客户端 A                         服务端 B
    |                                |
    | 目标 IP = 192.168.1.20         |
    |                                |
    v                                |
rdma_resolve_addr()                  |
    |                                |
    +-- 选择本地 RDMA 设备           |
    +-- 确定本地源地址               |
    |                                |
    v                                |
rdma_resolve_route()                 |
    |                                |
    +-- 解析到对端的网络路径         |
    +-- 获得路径相关参数             |
    |                                |
    v                                |
ibv_alloc_pd()                       |
    |                                |
    +-- 创建本地保护域 PD            |
    |                                |
    v                                |
rdma_create_qp()                     |
    |                                |
    +-- 创建本地 QP                  |
    |                                |
    v                                |
rdma_connect()                       |
    |                                |
    +-------- 连接请求 ------------->|
    |<------- 连接响应 --------------|
    |                                |
    v                                v
           RDMA RC 连接建立
```

记住三个区别：

- Address：确定使用哪个本地 RDMA 设备和地址。
- Route：确定如何通过 RDMA 网络到达对端。
- PD：本地资源的保护域，和网络路径解析没有关系。
