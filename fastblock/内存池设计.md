
# memory_pool.h

内存池模版，主要是用来构建 sq 和 rq 的任务池队列

```
template<typename work_request_type>
模版类型 主要是 sq 发送队列 和 rq 接受队列
```

```
struct net_context {
	::ibv_mr* mr{};
	work_request_type wr{};
	::ibv_sge sge{};
};
```

1. ibv_mr：注册后的 RDMA 内存区域
```
struct ibv_mr {
	struct ibv_context *context;   // 这块 MR 属于哪一个 RDMA 设备上下文
	struct ibv_pd *pd;             // 注册内存的起始虚拟地址
	void *addr;                    // 这块注册内存的长度
	size_t length;
	uint32_t handle;
	uint32_t lkey;
	uint32_t rkey;
};
```

2. ibv_sge：描述这块本地内存怎么使用
```
struct ibv_sge {
    uint64_t addr;
    uint32_t length;
    uint32_t lkey;  // 本地的key ，远端要使用需要对应的 rkey ，ibv_mr 里面记载的
};
```
