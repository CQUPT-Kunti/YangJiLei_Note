# noexcept

`noexcept` 是 C++11 引入的关键字，表示函数承诺不会让异常传播出去，并不是忽略异常。

```cpp
void func1() noexcept;        // 承诺不抛出异常
void func2() noexcept(true);  // 同上
void func3() noexcept(false); // 允许异常传播
void func4();                 // 默认通常允许异常传播
```

# unlikely / likely

`unlikely` 通常用于优化 `if` 分支，提高 CPU 执行效率。

是一种分支预测优化提示，告诉编译器：这个条件大概率不会成立。

## C++20 标准写法

C++20 引入了两个属性：

```cpp
if (ptr == nullptr) [[unlikely]] {
    return;
}

if (ptr != nullptr) [[likely]] {
    // 大概率执行
}
```
